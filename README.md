## About

uEssentials adds a broad collection of useful commands and management features to Unturned servers running RocketMod. This repository maintains the project with current dependencies, builds and community documentation.

## Features

- 86 documented commands for players, moderators and administrators.
- Searchable command and permission reference.
- Native kits and warps.
- Teleportation, inventory, vehicle and world-management tools.
- English, Spanish, Portuguese and Russian language support.
- Modular configuration and permission nodes.

## Documentation

The complete command reference, permissions and setup guide are available on the website:

### [Open the uEssentials documentation →](https://uessentials.terror.lol/)

The documentation supports English, Spanish, Portuguese and Russian, with automatic browser-language detection.

## Installation

1. Download the [latest release](https://github.com/TH3AL3X/uEssentials/releases/latest).
2. Stop your Unturned server.
3. Extract the archive into the server's <code>Rocket</code> directory, preserving the included folder structure.
4. Start the server once to generate the configuration files.
5. Configure commands and permissions for your groups.

> Always back up your server configuration before replacing an existing installation.
