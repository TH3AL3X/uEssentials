Política de privacidad

Última actualización: 26 de septiembre de 2026.

Esta web ofrece documentación gratuita sobre uEssentials. El buscador funciona por completo en el navegador y no envía las consultas a un servidor propio.

Hosting y registros técnicos

El sitio se aloja mediante GitHub Pages. GitHub puede tratar datos técnicos, como la dirección IP y registros de acceso, conforme a su propia política de privacidad.

Cookies y publicidad

En este momento la plantilla no instala cookies publicitarias por sí sola. Si se activa Google AdSense, proveedores externos, incluido Google, pueden utilizar cookies para publicar anuncios basados en visitas anteriores a esta u otras webs. Google y sus socios también pueden usar esas tecnologías para mostrar, limitar y medir anuncios. Los usuarios pueden gestionar la personalización desde la configuración de anuncios de Google.

Antes de activar anuncios personalizados en el Espacio Económico Europeo, Reino Unido o Suiza, configura una plataforma de gestión del consentimiento certificada por Google y actualiza esta página con los datos del responsable y los proveedores publicitarios elegidos.

Enlaces externos

El sitio contiene enlaces a GitHub y Discord. Al seguirlos se aplican las políticas de privacidad de esos servicios.

Contacto

Para consultas sobre esta web, abre una incidencia en el repositorio de GitHub. Antes de publicar el sitio con publicidad, sustituye este párrafo por un correo o medio de contacto del responsable.
